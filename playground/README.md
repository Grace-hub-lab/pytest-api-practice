# Python 基础练习区

学 Python 基础时用。每课一个文件，直接运行，看输出、改代码、再运行。

| 课 | 文件 | 内容 |
|---|---|---|
| 1 | `lesson01_types.py` | 变量、字符串、列表、字典 |
| 2 | `lesson02_control_flow.py` | if、for、while、列表推导式 |
| 3 | `lesson03_functions.py` | 函数、参数、返回值、装饰器 |
| 4 | `lesson04_errors_files.py` | 异常、文件读写、JSON、YAML |
| 5 | `lesson05_oop.py` | 类、对象、继承（框架核心） |

运行（在项目根目录、已激活 `.venv`）：

```powershell
python playground/lesson01_types.py
```

每个文件末尾都有「课后练习」，直接写在文件最下面运行验证即可。
自己写的其他练习文件也放这个文件夹，例如 `playground/my_test.py`。

> `playground/_tmp/` 是第 4 课运行时生成的临时文件，不会提交到 Git。
