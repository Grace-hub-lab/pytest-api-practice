# 家里电脑学习指南：从零开始学自动化测试

这份文档带你在家里的 Windows 电脑上完成三件事：

1. 装好学习环境（Python、Git、VS Code）
2. 把练习项目拉下来跑通
3. 按周学习：每一步学什么、去哪看视频、对照项目里哪个文件、做什么练习

> 这份文档就在 GitHub 仓库里：<https://github.com/Grace-hub-lab/pytest-api-practice/blob/main/docs/家里电脑学习指南.md>
> 家里电脑先用浏览器打开它，照着一步步做。

---

## 第一部分：安装环境（约 30 分钟，只做一次）

### 1.1 安装 Python

1. 打开浏览器，访问 <https://www.python.org/downloads/windows/>
2. 在 **Stable Releases** 下面找 **Python 3.13.x**，点 **Windows installer (64-bit)** 下载
   - 下载很慢的话，换国内镜像：<https://registry.npmmirror.com/binary.html?path=python/>，进 `3.13.x/` 文件夹，下载 `python-3.13.x-amd64.exe`
3. 双击安装包，**第一个界面最重要**：
   - ✅ 勾选底部的 **Add python.exe to PATH**（不勾的话后面所有命令都会报"找不到 python"）
   - 然后点 **Install Now**
4. 最后一个界面如果出现 **Disable path length limit**，点一下，再点 Close

**验证**：按 `Win + R`，输入 `powershell` 回车，在打开的蓝色/黑色窗口里输入：

```powershell
python --version
pip --version
```

能看到 `Python 3.13.x` 和 `pip xx.x` 就成功了。

> ❗ 输入 `python` 后弹出了 Microsoft Store：说明第 3 步没勾选 PATH。卸载后重装并勾上，或者在 Windows 设置 → 应用 → 高级应用设置 → **应用执行别名**里，把两个 "python.exe / python3.exe 应用安装程序" 关掉。

### 1.2 安装 Git

Git 是代码版本管理工具，用来在公司电脑和家里电脑之间同步代码。

1. 访问 <https://git-scm.com/download/win>，点 **Click here to download** 下载 64 位安装包
   - 慢的话用镜像：<https://registry.npmmirror.com/binary.html?path=git-for-windows/>，进最新版本文件夹，下载 `Git-x.xx.x-64-bit.exe`
2. 双击安装，**所有选项保持默认，一路点 Next**，最后点 Install
3. **关掉之前的 PowerShell 窗口，重新打开一个**（新装的软件要新窗口才能识别），输入：

```powershell
git --version
```

4. 设置你的名字和邮箱（提交代码时会记录，只需设置一次）：

```powershell
git config --global user.name "Grace"
git config --global user.email "你的GitHub注册邮箱"
```

### 1.3 安装 VS Code（写代码的编辑器）

1. 访问 <https://code.visualstudio.com/>，点 **Download for Windows**
2. 安装时，在"选择附加任务"页面，**把下面几项都勾上**：
   - ✅ 将"通过 Code 打开"操作添加到 Windows 资源管理器文件上下文菜单
   - ✅ 将"通过 Code 打开"操作添加到 Windows 资源管理器目录上下文菜单
   - ✅ 添加到 PATH
3. 打开 VS Code，点左侧边栏的 **扩展** 图标（四个方块，或按 `Ctrl + Shift + X`），搜索并安装：
   - **Chinese (Simplified) Language Pack**：中文界面，装完右下角提示重启就重启
   - **Python**（发布者 Microsoft）：Python 支持，会自动带上 Pylance
   - 可选：**YAML**（发布者 Red Hat）：YAML 文件高亮和检查

## 第二部分：在哪里执行命令

文档里所有灰色代码块里的命令，都在 **VS Code 的终端**里执行（不用另外开窗口）：

- 打开方式：VS Code 菜单 **终端 → 新建终端**，或按快捷键 `` Ctrl + ` ``（数字 1 左边那个键）
- 终端出现在 VS Code 下半部分，默认是 PowerShell，提示符类似 `PS D:\study\pytest-api-practice>`
- 复制命令 → 在终端里右键粘贴（或 `Ctrl + V`）→ 回车

> 提示符前面的路径就是"当前目录"，命令都是在这个目录下执行的。在 VS Code 里打开项目文件夹后，终端默认就在项目目录，不用手动切换。

## 第三部分：拉下练习项目并跑通（约 15 分钟）

### 3.1 下载代码

1. 在 D 盘（或任意盘）新建一个文件夹，比如 `D:\study`
2. 打开 VS Code → 菜单 **文件 → 打开文件夹** → 选 `D:\study`
3. 按 `` Ctrl + ` `` 打开终端，执行：

```powershell
git clone https://github.com/Grace-hub-lab/pytest-api-practice.git
```

- 如果仓库是 Private，会弹出一个 GitHub 登录窗口，点 **Sign in with your browser**，在浏览器里授权就行
- 如果卡住或报 `Failed to connect to github.com`，看文末「常见问题 Q3」

4. 下载完后，VS Code 菜单 **文件 → 打开文件夹** → 选 `D:\study\pytest-api-practice`
   - 弹出"是否信任此文件夹的作者"→ 点 **是，我信任**

### 3.2 创建虚拟环境并安装依赖

> **虚拟环境（.venv）是什么**：给这个项目单独准备的 Python 环境，装的包不会影响电脑上的其他项目。每个项目一个，是行业标准做法。

在 VS Code 终端里**逐行**执行：

```powershell
python -m venv .venv
```

（左侧文件列表里会多出一个 `.venv` 文件夹）

```powershell
.\.venv\Scripts\Activate.ps1
```

成功后提示符最前面会出现 **`(.venv)`**。

> ❗ 如果报红字「因为在此系统上禁止运行脚本」，先执行下面这一行，然后再执行一次上面的 Activate：
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```
> 问你是否更改时输入 `Y` 回车。

```powershell
pip install -r requirements.txt
```

> 如果下载很慢或超时，改用清华镜像：
> ```powershell
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

### 3.3 让 VS Code 使用这个虚拟环境

1. 按 `Ctrl + Shift + P`，输入 `Python: Select Interpreter`，回车
2. 选带 **`.venv`** 字样的那一项（类似 `Python 3.13.x ('.venv': venv)`）

之后 VS Code 新开终端会自动激活 `.venv`，代码里也不会再有"找不到模块"的波浪线。

### 3.4 跑起来

```powershell
python run.py
```

最后看到 **`12 passed`** 就成功了 🎉

查看报告：在 VS Code 左侧找到 `reports/report.html`，右键 → **在文件资源管理器中显示** → 双击用浏览器打开。

### 3.5 用 VS Code 的测试面板跑（可选，更直观）

1. 点左侧边栏的 **测试** 图标（烧杯形状）
2. 点 **配置 Python 测试** → 选 **pytest** → 选 **. 根目录**
3. 左侧会列出所有用例，点每条旁边的 ▶ 单独运行，点 🐞 可以打断点调试

> 调试是学习时最有用的功能：在代码行号左边点一下设红点（断点），用调试模式运行，程序会停在那里，你可以看每个变量的值。

## 第四部分：两台电脑之间同步代码

在任意一台电脑上，**每次学习都按这个顺序**：

```powershell
git pull                          # ① 开始前：拉取另一台电脑推上来的改动
# ② 写代码、跑用例……
git add .                         # ③ 结束时：把改动加入暂存
git commit -m "完成练习题1"        # ④ 提交，引号里写你做了什么
git push                          # ⑤ 推到 GitHub
```

- 只要记住「**先 pull 再写，写完就 push**」，基本不会遇到冲突
- 想看改了哪些文件：`git status`
- VS Code 左侧的 **源代码管理** 图标（分叉形状）也能点按钮完成 add/commit/push，不想记命令可以用它

## 第六部分：常见问题

**Q1：输入 `python` 提示"不是内部或外部命令"，或者弹出微软商店**
安装时没勾 Add to PATH。重新运行安装包 → **Modify** → 下一步 → 勾选 **Add Python to environment variables** → Install。然后关掉所有终端，重新打开。

**Q2：`pip install` 很慢或报 timeout**
加国内镜像：`pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple`

**Q3：`git clone` / `git push` 报 `Failed to connect to github.com port 443` 或卡住不动**
家里网络访问 GitHub 不稳定。多试几次，或换个时间段/网络（比如手机热点）。如果你使用代理软件，需要给 git 配置代理（端口号看你的代理软件设置）：

```powershell
git config --global http.proxy http://127.0.0.1:端口号
```

不用代理时取消：`git config --global --unset http.proxy`

**Q4：VS Code 里 import 下面有黄色/红色波浪线，提示找不到模块**
没选对解释器，回到第 3.3 步选 `.venv`。

**Q5：每次打开 VS Code 终端都要激活 .venv 吗？**
做完 3.3 后，新开的终端会自动激活。如果提示符前没有 `(.venv)`，手动执行 `.\.venv\Scripts\Activate.ps1`。

**Q6：用例失败了看不懂报错**
从下往上看：最后的 `E   AssertionError: ...` 是失败原因，往上是出错的代码行。看不懂就把整段报错复制下来问 Kiro。

**Q7：`git pull` 提示冲突 (CONFLICT)**
说明两台电脑改了同一个文件的同一处。VS Code 会把冲突的地方标出来，点「保留当前更改 / 保留传入的更改」选一个，保存后 `git add .`、`git commit -m "解决冲突"`、`git push`。
